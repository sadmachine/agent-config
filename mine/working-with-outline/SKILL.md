# Working With Outline

Outline is shared with the team, and a published change is visible immediately. Every write is **draft-then-confirm**: write only the content the user has approved, as written.

Writes include creating a document, editing or appending to one, publishing a draft, moving, archiving or deleting, commenting, and changing permissions or share links.

1. Print the exact proposed content in chat, in full, and name the target document and its parent.
2. Ask for approval, then stop. This ends your turn.
3. Create or update only after the user's next message approves that content.

Approval is a user message responding to the content you printed. These are **not** approval:

- Choosing an option in an `AskUserQuestion`, including an option that says to publish. That selects a plan; the content is still unwritten and unseen.
- Approval of an earlier write. Each write is approved on its own.
- The user supplying a document link, or asking for something to be documented.

When the user asks for changes, print the revised content in full and ask again.
